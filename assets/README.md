# SVG assets

The SVG files in this directory are original, editable vector illustrations for the project README and documentation. They are deliberately self-contained and use no external image dependencies.

- architecture.svg: end-to-end system diagram.
- claude-web.svg: remote client.
- cloudflare-worker.svg: public Worker gateway.
- durable-object.svg: connection coordinator.
- local-agent.svg: local relay process.
- mcp-protocol.svg: MCP protocol.
- websocket.svg: persistent transport.
- security.svg: authentication and trust boundary.
- terminal.svg: local command line.
- claude-code.svg: local Claude Code process.
